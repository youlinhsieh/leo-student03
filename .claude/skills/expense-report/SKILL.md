# expense-report：發票 → A4 掃描 → CSV → 人同意 → 寄會計

一條直線，**不能跳步、不能倒過來**：

```
發票貼 A4 → 掃描檔 → 你辨識 → 寫 CSV → 程式檢查 → 給人看 → 人說「寄」 → 寄給會計
```

## 檔案放哪

每個月一個資料夾（月份＝報帳的月份，問不出來就用今天的月份）：

| 位置 | 是什麼 |
|---|---|
| `course/expenses/<YYYY-MM>/scans/` | A4 掃描檔（PDF／JPG／PNG）。**不進 git**（`.gitignore` 已排除），雲端工作區關掉就沒了，原稿請人自己留 |
| `course/expenses/<YYYY-MM>/expenses.csv` | 報帳明細，UTF-8 含 BOM（Excel 直接開不會亂碼）。進 git |

## 步驟

### 1. 收掃描檔：一律 A4

- 請人把發票**貼在 A4 紙上**再掃描，上傳到 `scans/`。一張 A4 可以貼多張發票，不要重疊、不要蓋住號碼或金額。
- 收到檔案先檢查是不是 A4 掃描：PDF 看頁面尺寸（約 595×842 pt）；圖片看長寬比約 1:1.414（直放或橫放都可以），可用 `node .claude/skills/expense-report/scripts/expense-check.mjs --page <檔案>` 檢查。
- **不是 A4 的一律退件**：手機隨手拍的單張發票、截圖、長條收據照片都不收。用一句白話請他「貼在 A4 上重掃」，不要自己裁切或硬辨識。
- 電子發票也一樣：請他印出來（或印證明聯）貼在 A4 上掃描。

### 2. 辨識：一張發票一列

用 Read 讀每個掃描檔，逐張發票辨識下列欄位，寫進 `expenses.csv`（檔案不存在就建，第一行是欄位名）：

```
序號,掃描檔,頁/位置,發票日期,發票號碼,賣方名稱,賣方統編,買方統編,品項摘要,未稅金額,稅額,總金額,用途分類,報帳人,辨識信心,備註,狀態
```

- **發票日期**：西元 `YYYY-MM-DD`（民國年加 1911）。
- **發票號碼**：統一發票寫成兩個英文字母加八位數字，例如 `AB12345678`；收據沒有號碼就留空，並在備註寫「收據」。
- **統編**：八位數字；沒有就留空。買方統編應該是店的統編（問不出來就照發票上寫的填）。
- **金額**：只寫整數、不加逗號和「元」。發票只印含稅總額時，未稅和稅額留空。
- **用途分類**：從 `食材`、`包材`、`設備`、`水電瓦斯`、`交通`、`雜支` 挑一個；拿不準就填 `雜支`，備註寫原因。
- **頁/位置**：例如 `p1-左上`，讓人拿著 A4 原稿對得到是哪一張。
- **辨識信心**：`高`／`低`。字糊掉、被折到、看不清的欄位**不要猜**：留空、信心填 `低`、備註寫看不清哪裡。
- **狀態**：新寫進去的一律 `待確認`。

### 3. 程式檢查

```bash
node .claude/skills/expense-report/scripts/expense-check.mjs course/expenses/<YYYY-MM>/expenses.csv
```

它檢查欄位、日期、發票號碼格式、統編檢查碼、未稅＋稅額＝總額，以及**同一張發票號碼有沒有報過兩次**（同一份 CSV 裡，也比對 `course/expenses/` 底下其他月份）。有錯先回去看掃描檔改正；真的看不清就留空、標 `低`，**不要為了過檢查去改數字**。

### 4. 給人看，等他同意

把要報的這批（狀態 `待確認` 的列）整理成一張表給人看：日期、號碼、賣方、分類、總金額，最後一行寫合計和張數；信心 `低` 的列和檢查出的警告**放在最上面**。然後只問一句：

> 「這 N 張、合計 $X，這樣對嗎？對的話我就寄給會計。」

- 他改哪裡就改 CSV，重跑步驟 3，再給他看一次。
- **他明確說「對／寄」才算同意**。沒回答、說「等等」、只改了一部分都不算。這次同意只管這一批，下一批要重新問。
- 同意後把這批的狀態改成 `已確認`。

### 5. 寄給會計

- **會計的 email**：問人一次（只問「要寄給哪個信箱」），不要寫進 repo 的任何檔案。
- 寄出的內容：主旨 `里歐烘焙坊 <YYYY-MM> 報帳（N 張，合計 $X）`，內文是步驟 4 那張表，附件是 `expenses.csv`（只附這批的列；有需要再附 A4 掃描檔）。
- **有寄信的連接器**（例如 Gmail）就用它寄，寄之前把收件人、主旨、附件再說一次；**沒有**就把信件草稿和 CSV 路徑給人，請他自己寄，**不要說「已寄出」**。
- 確定寄出後把這批的狀態改成 `已寄出`，備註加上寄出日期，存檔（commit＋push），用一句白話說存了什麼。

## 鐵律

- **沒貼 A4、沒掃描的不收。** 不幫忙辨識隨手拍的發票。
- **沒有人明確同意，絕對不寄。** 寄出去就收不回來。
- **不猜數字。** 看不清就留空、標 `低`、告訴人。金額和統編錯了，會計那邊會出事。
- **不改已寄出的列。** 寄錯要更正就另外寫一列，備註寫「更正第 N 列」，再走一次步驟 4、5。
- 會計信箱、銀行帳號這類資料不寫進任何檔案；掃描檔不進 git。
